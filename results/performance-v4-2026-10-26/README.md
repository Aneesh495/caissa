# Saved v4 actor performance

The full performance producer and independent reader passed with the exact saved
1ff executable, 52d network, original selected checkpoint and unchanged mixture.
Both exact optimizations and deferred neural state were enabled. The sample used
four evaluator modes, 1/2/4/8 threads, eight positions and five repetitions at
250 milliseconds per search.

All 640 timed searches, 4,581 actual memory observations and 2,000 readiness
requests were independently reconstructed. The reader also executed all 16
fixed-node scalar/native comparisons. The idle readiness 99th percentile was
0.026959 milliseconds; during search it was 3.719101 milliseconds. The separate
single stop observation was 0.155916 milliseconds and is not a stop percentile.

The owner retained its actual exclusive host lease, process and power samples,
source inventory, copied actor lineage, raw output, stage exits and closed
resource ledger. Every published record is listed in `MANIFEST.json`. The public host samples
omit process command lines and arguments after local app session values were
found in those arguments. `PUBLIC_REDACTION.json` records the original hash and
the derived public hash. Original raw bytes remain private, original run receipts
are unchanged, and Git history has not been rewritten. Current-tree redaction
does not revoke previously exposed session values. Residual
system load is visible in the actual samples; a lock alone does not prove an
otherwise idle machine. The exact executable and network identities remain
pinned, while complete portable deployment packaging is still required.

These measurements do not establish a playing-strength gain, parallel match
strength, race safety, a full G04 stop sample or project acceptance. Final
source/deployment binding and other required gates remain pending. All earlier
failed and diagnostic performance scopes retain their original status.
