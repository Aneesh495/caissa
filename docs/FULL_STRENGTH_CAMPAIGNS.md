# Full fixed-sample strength ownership

`tools.full_strength` runs the two prospectively frozen strength campaigns only after the full model owner has completed all three original seed budgets and validation-only selection. A completed model campaign with a disclosed learned-loss failure may still supply the selected model for planned strength measurements. That failure remains failed. No match outcome changes the chosen network, mixture, seed or settings.

The neural campaign contains 2000 opening pairs. The external campaign contains 334, 333 and 333 pairs against pinned Stockfish 19 settings. Each complete campaign has its own twelve-hour cumulative ceiling, three maximum recovery attempts, ten-GiB free-space reserve and twenty-GiB additional-artifact ceiling. Resume preserves source, model, openings, resources and the original deadline. The original failed corpus recovery remains failed. Its separately declared v2 continuation and the unstarted model scope each have a 24-hour wall ceiling and six cumulative active hours. The match ceilings are separate.

Both neural and classical actors use the same saved executable, one thread, 16 MiB hash, 100 ms per move, one-node warmup, 150 ms transport allowance and the same exact search optimizations. The baseline retains original classical evaluation contract 1. Neural bounds and scoreless ordering hints stay off. Completed games and actual time forfeits survive a restart, and partially completed pairs are reconstructed from their committed game journals.

Before play, the owner archives committed source, pins the selected model receipt, model bytes, executable, protocol and opening file, and records the actual process inventory. During execution it samples load and process state every five seconds. A concurrent known compiler, data generator/preparer, trainer, arena or performance producer stops the owned stage. The owner preserves its actual failure and requires a bounded recovery within the same deadline. It does not stop unrelated processes. Host snapshots make residual user/system load visible; process-name detection does not prove an otherwise idle machine.

The independent neural checker reconstructs every legal game, PV, actual UCI budget/history request, time loss, color reversal and opening-family bootstrap. It enforces the unchanged 4000-game, at-least-50-Elo estimate and positive 95-percent lower bound. A failed endpoint is retained after the full sample. Independent external verification enforces all three pinned option sets, exact setting-specific sample sizes, selected candidate model, full resources and every game before reporting separate relative estimates. Stockfish option labels do not establish Caissa's absolute Elo.

Contract controls reject changed time, hash, threads, workers, samples, transport, adjudication and resource ceilings. Actual transport probes configure all eight candidate/opponent combinations against the original native engine and pinned Stockfish binary. These are one-thousand-node probes, not strength games. Full campaigns have not started while full data reconstruction is still running.

After committing the fully frozen v3 protocol and completing the full model owner, launch the neural campaign with `python -m tools.full_strength neural --protocol config/protocol-v3.json --expected-protocol-sha256 SHA --model-campaign runs/searched-full-model-v3 --expected-model-campaign-sha256 MODEL_RECEIPT_SHA`. Run the external campaign separately with `external` and `--stockfish` pointing to the pinned local executable. Reuse `--resume` only with its archived original owner source and remaining ceiling.

The owner reports domain observations with `full_acceptance: false`. Full release still requires the independent complete-project verifier, all other gates and the private release audit.

The independent checker also requires the complete original-engine option inventory. Adding `Use Table=false` to both actors cannot hide behind equal-resource comparison, and weakening only the classical actor is rejected. Six controls cover extra pruning/scalar switches, a missing model path, changed mixture and altered hash resources. This new verifier component has a separate 120-second development bound, retained in `results/full-actor-contract-2026-10-24`; it does not renew either timed-match ceiling.

The first actual UCI preflight failed because the candidate enabled `Use Neural` before its `EvalFile` had loaded. Configuration now respects that dependency. All eight transports then passed, and a further final run exercised the independently implemented setting map. The original failure, successful probes, thirteen setting/ceiling rejections, nineteen frozen-model protocol controls and four rehashed game failures are retained in [the owner evidence](../results/full-strength-owner-2026-10-24/). They share the original 600-second development ceiling.
