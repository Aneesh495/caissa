# Full performance replay

The G13 adapter stages all eight declared artifact references from pinned
evidence, including actual measurements, memory samples, command latencies,
session handshakes and scalar correctness cases. Its independent child
recomputes aggregates and reruns the saved native and scalar fixed-node cases.
Saved success fields cannot replace that reconstruction.

The full workload retains 1/2/4/8 threads, eight or more positions, at least
five repetitions, 250 ms searches and 1,000 command latency samples. The
observed host must support eight CPUs. The actor and selected network must
match deployment identities. All related cases use the same deferred neural
state option as the frozen actor. Legacy profiles without that option retain
their original interpretation and cannot be promoted to this new profile.

The independent child shares its bounded campaign's process group, including
the native replay process. Timeout cleanup can therefore stop that owned
work. Standalone native sessions retain their separate-group default.

Metadata controls and tiny native ownership probes are implementation checks.
They certify no full timed sample. Full G13 still needs actual final-host
measurements and independent replay after decisive matches release the host.
G10 additionally needs its separate strength and race evidence. Throughput,
depth, latency and evaluator cost are never converted to Elo.
