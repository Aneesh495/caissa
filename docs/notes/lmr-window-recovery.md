# Recovering a reduced move without PVS

The heuristic switch study prompted a review of the interaction between late-move reductions and PVS. A reduced move first receives a narrow scout window. If it improves alpha, the implementation retries at full depth. With PVS enabled, a result inside the principal window receives a later full-window search. With PVS disabled, that later recovery was absent, so the full-depth retry also needs the original window.

The repair in `src/search.cpp` uses `[-beta,-alpha]` for that retry when PVS is off, while retaining `[-alpha-1,-alpha]` and the existing later recovery when PVS is on. Other heuristics and the classical evaluator are unchanged. This repairs an off-switch interaction; no measured Elo improvement is claimed.

The fixed witness is `8/8/2k5/8/2P5/2K5/8/8 b - - 0 1` at depth five, with PVS off, LMR on and other selective mechanisms off. The old native search returned -139 cp. Independent exhaustive mailbox minimax enumerated 18642 nodes and returned -196 cp. The repaired search also returns -196. The new `tests/lmr_window_test.cpp` checks all four PVS/LMR combinations and requires the regression to exercise both reductions and recovery. Linking that exact regression against the original library failed with a real exit 1 before linking it against the repair passed.

The broader investigation retained every result for eight pawn endings at depths four and five, each with LMR on and off. Without LMR, all sixteen oracle comparisons agree for both executables. With LMR, four old scores differed from exhaustive minimax; the repair resolves one. Three differences remain because the reduced-depth fail-low path is still selective. One retained position still chooses a different move from the nonselective search. This repair does not establish general minimax equivalence with LMR enabled, nor erase those negative cases. Nonselective exact-search requirements remain separately tested.

All seventeen Release and seventeen ASan/UBSan native cases passed. Forty-eight old/new pairs, 96 actual native queries, also preserved PVS-enabled results and non-timing work counters at 5000/25000 nodes across classical, ten-percent residual and pure neural modes. That parity uses the old diagnostic network, not the new training campaign or a selected test result. The initial parity driver enabled neural evaluation before loading its model; that actual failure and its 32 completed classical queries remain in the evidence. The corrected ordering completed within the original cumulative 1800-second investigation deadline, which was never reset.
