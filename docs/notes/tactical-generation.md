# Lazy tactical move generation

Quiescence previously built every legal move before a stand-pat cutoff, then discarded quiet moves. The optional `Tactical Generation` path first asks whether any legal move exists. This preserves checkmate and stalemate decisions before evaluation. In-check nodes still generate every legal evasion. Other quiescence nodes materialize captures, en passant and all four promotions only after stand-pat and the existing depth limit permit a search.

A single original pseudo-move enumerator now serves full collection, tactical collection and an allocation-free early exit. It preserves the previous piece and destination ordering. The legality context checks pins, single/double-check evasions, king destination attacks and en passant discovered attacks. Castling stays in full generation. A quiet promotion remains tactical. The independent mailbox generator shares none of this code.

`MoveAvailability` carries the board key, check status and existence of a legal move. Only `Position` constructs it. Rules reject a stale board key. A restored position may reuse its availability, but rule clocks, repetitions and synthetic-path rules are evaluated again. A repeated board can therefore acquire a valid claim without changing its legal-move availability. This value is a local query result, not a persisted or cross-position legality cache; it uses the engine's existing 64-bit identity assumption.

The search option remains off by default. Classical evaluation, node accounting, move ordering, search windows and draw semantics are unchanged. Both exact optimization switches are enabled in the prospective full experiment for both the neural actor and its unchanged classical evaluator. No full experiment or strength result is certified here.

The new native suite checked 20000 seeded positions against stable filtering and the independent mailbox. It exercised all fields used by board, repetition and search identity before and after queries, stale normal/null moves, restored availability, repetition claims, promotions, en passant, Chess960 overlap castling, checkmate and stalemate. All 168 fixed-node search pairs preserved best move, PV, completed depth, score, logical tree counters and evaluator requests across classical, both saved network formats, scalar inference, cache and quiescence-disabled cases.

All 15 Release tests and all 15 ASan/UBSan tests passed. The instrumented build uses `RelWithDebInfo` so the exact existing cache and neural cases fit the declared ceiling. This new source campaign finished in 90.83 seconds within its separate 4800-second limit. The earlier cache campaign's exhausted 1800-second budget and interrupted sanitizer case remain recorded as failures; they were not resumed or relabeled.

The three-way replay compared 100000 reachable positions with Python chess and the older frozen native executable. It observed 96573 distinct identities, 3913 checked positions, 9048 legal promotion alternatives, 399 en passant alternatives and 25708 Chess960 positions. Full move sets, check status, native position identities, tactical sets and existence queries agreed. All 20 frozen perft fixtures also passed. These observations do not replace final release-source binding.

A separate 144-search cost profile compared both switches off with both on, using eight positions, three repeats and classical/ten-percent/full-neural modes. The independent checker reran every saved request and checked legal PVs, timestamps, tree counters, aggregates and ratios. Twelve actual observations completed no depth and returned legal fallbacks, with no invented score or PV. Six rehashed corruptions were rejected, including an illegal PV, changed node budget, altered parsed score, concealed completed-depth PV, fabricated timing ratio and changed mode.

Median combined/original roundtrip ratios were 0.929 classical, 0.868 mixture and 0.779 full neural. Mixture inference calls fell from 337569 to 159489. The corpus replay was active, and individual ratios reached 4.235. These short, noisy timing observations establish neither universal speedup nor Elo. The selected full model, controlled timed matches and full systems campaigns remain pending.
