# Exact static evaluation cache

Each search worker can own a 32768-entry direct-mapped cache for exact static evaluations. A valid bit distinguishes an empty entry from key or score zero. Lookup compares the entire 64-bit board key, and a different key at the same index replaces the old entry. The hash collision assumption matches the existing transposition table. At the current ABI the storage is 512 KiB per enabled worker, at most 4 MiB across eight workers. This is additional to the configured transposition-table memory and is reported separately.

The value is the underlying evaluator's exact score, before draw-claim handling, search windows or mate-distance decisions. Classical contract 1 and the neural feature model depend on board placement and mover, so earlier history and rule clocks do not alter that raw score. Search still evaluates legal termination and draw history before considering static evaluation. A worker's network, neural percentage and scalar/native choice are immutable for its lifetime. Workers are rebuilt for each search, preventing reuse across model or option changes. No cache state is shared across threads.

Only a complete evaluation can enter the cache. A certified stand-pat lower bound is deliberately not stored. A previously cached exact score remains usable at another threshold. The cache does not store a claim score, quiescence result, TT bound or mate score. The unchanged classical evaluator remains the comparison control.

`Evaluation Cache` is an off-by-default UCI option. `evaluation_cache_hits` and `evaluation_cache_bytes` appear in search statistics. `eval_calls` counts evaluation requests, including cache hits; `neural_evaluations` counts actual complete network inferences. Timing includes the lookup. Disabling the option allocates no cache.

The native test covers key/score zero, forced index collisions, rejection of mate/bound sentinels, standard and Chess960 positions, actual repetition history, neural and classical evaluators, scalar mode, fixed-node PV/score/tree-counter equality, private multi-thread memory and certified-bound interactions. It passed 120 paired native cases with 625195 requests and 236432 hits. All 14 release native tests passed. The sanitizer run passed the prior 13 cases, then its final cache case was terminated at the real wall deadline during a large wall/active-time gap. The 1800-second development budget remains exhausted. This is incomplete sanitizer evidence, so the feature stays disabled and cannot claim full systems acceptance.

A separate fixed-node cost experiment retained 144 actual searches over eight positions, three repeats and classical/ten-percent/full-neural modes. Every cached/uncached pair preserved its outputs and search-tree counters. Twelve observations exhausted the node budget before completing a depth and returned actual legal fallback moves; they have no invented PV or score. The independent checker reran every query through the saved executable, reconstructed legal PVs, request timing, counters, aggregates and ratios without importing producer transport or parsing code.

In the ten-percent mode, actual network inferences fell from 337569 to 159489. Median cached/uncached roundtrip ratio was 0.829; the classical ratio was 0.949 and the full-neural ratio 0.890. The corpus verifier was active during this small cost run. Timing is descriptive under that load; it is not an Elo measurement or evidence of isolation. A position's measured timing ratio reached 1.623, so the median does not describe every position.

Failures remain visible. The initial native fixture failed to compile because its initializer mixed `string_view` and string literals. Independent replay first exposed a redundant forced-signal cleanup race; graceful protocol teardown corrected it. It then rejected a real zero-completed-depth fallback under an overly strict PV requirement. The checker now accepts only a legal fallback with actual zero completed-depth nodes. An initial textual fix left the old requirement in place and its failed replay is also retained. All successful cost replay work remained inside its original 900-second scope. Additional proposed parser controls did not run because that scope had expired, and are recorded as not executed.

[Raw native, sanitizer, cost and independent replay records](../../results/evaluation-cache-2026-10-24/) preserve the actual failures and identities. `verification/native_session.py` owns finite nonblocking native pipes and cleanup; `verification/evaluation_cost.py` interprets the frozen observations and checks the saved engine independently. The current metadata/observation ceilings are 1 MiB/128 MiB. Further full-source sanitizer, strength and systems measurements remain required.
