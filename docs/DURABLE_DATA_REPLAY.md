# Durable independent data replay

The first separately authorized six-hour finalization exported the retained arrays, then failed its independent replay deadline during prolonged host sleep. Its last progress counter reported 98816 source pairs and 197632 completed games. No complete data-verification receipt was produced. The original acquisition failure and this recovery failure remain unchanged.

That verifier used a temporary SQLite index with journaling disabled. After termination, even a read-only schema query returned `database disk image is malformed`. The scratch file is preserved for forensics and cannot supply a trusted continuation. The original game journals and exported arrays are separate inputs; their identities remain pinned.

The replacement verifier uses full-synchronous WAL transactions. Expected inputs, contributor records, source cursor, counters and prefix digest commit together. An interrupted batch cannot advance the cursor independently of its rows. Prepared arrays are still checked completely, including on a resume after the game-reconstruction phase. No model/test-selection metric is used by this structural verifier.

Resume requires an externally retained fingerprint of the stopped database and WAL bytes, plus identical data, holdout, protocol and verifier source bindings. An untrusted checkpoint cannot certify itself by rewriting a nearby metadata file. The owner acquires the index lock and pins only the stopped index from its own prior attempt. The resumed verifier rechecks those bytes before opening SQLite and rehashes the completed original source prefix before trusting its cursor. Old unversioned or corrupt scratch databases are rejected.

Real controls killed the new verifier with SIGKILL after a positive committed cursor, then completed the same retained 200-pair reconstruction with exactly the uninterrupted result: 400 games, 28088 raw samples and splits of 17654/2563/2108. Separate forced termination spilled uncommitted pages into WAL and altered the cursor inside the uncommitted transaction. Both the pages and cursor rolled back. Wrong and missing external pins were rejected. The initial fixture-path error is retained with its successful bounded correction. No new games were generated by these controls.

The human subsequently requested active continuation without recurring six-hour approval prompts. The new v2 recovery therefore declares a separate 24-hour wall ceiling and six cumulative active hours. The prior failed six-hour run is not extended or relabeled. Active time is measured with this host's monotonic clock, persisted separately, and carried across attempts. Closed owners stop charging active time; an unclosed owner is charged conservatively. Either exhausted ceiling stops the scope. Missing or invalid active ledgers cannot grant a fresh budget.

The new host policy records power state and holds a scoped display/idle-sleep assertion. It allows battery operation. Sleep can still occur, so durable checkpoints preserve useful completed work. This changes no system-wide power setting. Wall and active stage limits are explicit and separate; the old protocols retain their original equal-clock behavior. Synthetic clock controls verified that a wall-time jump does not consume unused active allowance and that a resumed active budget is never reset.
