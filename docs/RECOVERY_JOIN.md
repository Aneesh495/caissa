# Historical recovery evidence and saved native image join

This is a new all-component recovery audit. It downloads the exact prospectively
pinned ZIPs from the completed arena, training and original-data recovery
campaigns. It never invokes those producers, trains a model, acquires data,
forces another SIGKILL or repeats the old negative-control suites.

The independent reader hashes each whole original ZIP against the public
artifact pin, selects only its original positive raw directory, checks namespace,
file type, CRC and decompression bounds, and preserves every original receipt,
configuration, source label and engine identity. It reconstructs the original
partial arena pair/PGNs, all saved training checkpoint/optimizer/sampler/RNG
states and committed SQL positions/targets/contributors/splits through the
existing independent readers. Saved component success flags are insufficient.

For each component, explicit production and relevant serialization/validation
footprints must match the actual historical Git blobs and file modes. The
historical and current tracked native inventories must also match. The frozen
profile lists every covered file. Changed current producer bytes or modes fail,
even when they belong to a real new commit and ordinary declarations are rehashed.
The independent readers themselves execute from the externally trusted current
source. This does not equate every file of different historical product commits.

On macOS, the exact original 1ff executable, 52d network and unchanged 92d receipt
must additionally pass the independent tracked-source/input boundary. The
current arena then resumes one separate copy of the preserved partial pair with
that saved image. One old committed game remains byte-identical; three missing
diagnostic games must reproduce the original deterministic moves/outcomes. The
new execution records both the historical provenance and final executable. It
does not edit the historical archive's executable or claim the old component ran
the new image. These are recovery diagnostics, never strength games.

Linux reconstructs its original platform artifacts and verifies source joins.
It cannot execute the saved Mach-O image, so its result stays a component with
the final-image sample pending. Full G11 sample acceptance requires the macOS
final-image probe and all three original reconstructions. Other full gates,
compiler attribution, complete source/evidence coordination and release remain
separate requirements.

The full entry supports `forced-recovery-join-v1` with one exact
`recovery_join.config` reference and the complete declared input/archive inventory.
It stages byte-pinned inputs outside the original bundle and recomputes the join.
Old component drivers retain their original strict source/program contracts.

Input downloading has one 180-second combined clock. The independent join has
one 300-second clock, original reader ceilings of 60 seconds each and a final
native ceiling of 60 seconds. Output stays below 4 GiB with a 10 GiB reserve.
The separately frozen development scope bounds hosted attempts and total compute.
The GitHub credential is stripped before the artifact-storage redirect and is
removed before any native diagnostic process begins.
