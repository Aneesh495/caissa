# Limitations

Caissa has no defensible absolute Elo rating. Paired comparisons measure relative performance at their exact hardware, openings and resources. Stockfish strength option names are not interchangeable with an independently rated population. An earlier classical diagnostic lost every warm Stockfish game. The completed original q1024 external sample measured -392.39 relative Elo against unrestricted Stockfish 19, with a 95% interval of [-438.13,-353.45]. The new q4096/deferred actor is a separate unfinished measurement.

The learned evaluator has not demonstrated a positive contribution. The shipped network is diagnostic, and the browser uses classical evaluation. King-bucket sparse features omit castling rights, en passant, rule clocks and history. Search owns those rule conditions; functional-input deduplication deliberately merges omitted distinctions before training splits.

A bare FEN cannot reconstruct repetition history or prove historical reachability. Structural validity checks reject many impossible states but do not solve general reachability. Conservative dead-position detection recognizes selected proven material patterns, not arbitrary fortresses. The engine claims current valid draws when the arena policy requests them; intended-move claims are not a general user-facing claim interface.

Root splitting shares a safe table and cancellation but has not demonstrated linear scaling or superior strength at every thread count. A mutex design and successful race instrumentation cover observed paths, not an unconditional proof of the whole program. Supported service budgets are intentionally smaller than arbitrary desktop UCI budgets.

There is no tablebase adapter, cloud execution, distributed trainer, opening book or imported engine code/weights. These are not runtime dependencies. Hardware-specific native kernels fall back to the scalar implementation where unavailable. Windows has not been validated.

Full source-bound acceptance and release remain incomplete. Development diagnostics cannot substitute for the required data, neural gain, external sample, browser and performance campaigns. See [build status](BUILD_STATUS.md) for the explicit gate state.
